# EVENT ተራ 🎉

**EVENT ተራ** is a centralized web platform designed to help **AASTU students** easily discover, explore, and RSVP for campus events.

Instead of searching through scattered Telegram channels and notice boards, students can use one streamlined website to find **cultural, academic, and social events** happening around campus.

The platform also provides a secure dashboard for **student clubs and event organizers** to publish, manage, and monitor their own events efficiently.

---

## ✨ Key Features

### 🎯 Event Discovery
- Browse upcoming campus events in an attractive grid layout
- View featured event posters and highlights

### 🗂️ Category Filtering
- Filter events by:
  - Arts & Culture
  - Music
  - Technology
  - Community

### 📄 Event Details Page
- Full event descriptions
- Date and time
- Venue/location
- Organizer information

### ✅ RSVP System
- Securely reserve spots for events
- Simplifies attendance management for students

### 🛡️ Admin Dashboard
- Organizer registration and login
- Create and publish new events
- Upload poster images
- Manage or delete outdated events

### 📱 Responsive Design
- Fully optimized for:
  - Mobile phones
  - Tablets
  - Desktop devices
